# Plan: Round Selection, Records, and Arena Platform Redesign

## Goal

- 이지 라운드 선택을 숲·광산 탭과 4×2 타일로 바꾸고, 해금된 타일에서 한 번에 전투를 시작한다.
- 기록을 모드·스테이지 탭으로 나누고, 이지는 라운드 표, 하드는 스테이지 최고·최근 기록 카드로 보여 준다. 두 화면은 확정한 C 미니멀 스타일을 사용한다.
- 숲과 광산에 각각 3개의 수작업 발판 배치와 전용 도트 그래픽을 제공한다. 스테이지별 1개 배치에 다층 점프 경로를 두고, 기존 하드 저장은 동일한 발판과 위치에서 복원한다.

## Scope

- 일반 이지 선택기의 타이틀 진입과 전투 후 진입에 같은 새 화면을 사용한다. 마우스·터치·키보드에서 동작하고 잠금 및 뒤로 가기를 유지한다.
- 새 시도에만 수작업 배치를 선택한다. 하드 진행 중 배치와 기록, 설정, 사망 횟수는 보존한다. 구형 무작위·직사각형 발판 데이터의 읽기 경로를 유지한다.
- 개발용 라운드 선택 UI, 별도의 전투 결과 팝업, 바닥·아레나 경계·카메라·공격 규칙은 계획 범위 밖이다.
- UI T01/T02는 팝업 뼈대를 공유한다. T03은 기존 그래픽으로 동작시킬 수 있는 배치를 제공하고, T04에서 전용 그림으로 교체한다.
