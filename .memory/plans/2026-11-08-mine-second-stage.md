# Plan: 光산 두 번째 스테이지

## Goal
숲을 완료하면 해금되는 광산 1개를 추가한다. 광산의 세 종류 적, 수레, 두 보스, 화면과 소리를 구현하고 두 스테이지에서 체크포인트 없는 사망·이어하기·개별 기록을 제공한다. 숙련 플레이 목표는 광산 2~5분이며 실측과 조정이 필요하다. 확정 사양: [결정 D01~D21](../decisions/2026-11-08-mine-second-stage.md).

## 의존성과 완료 기준
- T01 → T02 → T03 → T04 → T05 순서. 앞 Task의 공개 인터페이스를 뒤 Task가 확장한다.
- 각 Task는 해당 시점의 `npm test` 및 `npm run build`를 통과한다. T02~T03의 광산 시뮬레이션은 T04 이전에 일반 사용자에게 해금하지 않는다.
- T01에서 기존 v1 게임 저장의 진행·기록·설정을 자동 초기화한다는 사용자의 명시적 결정을 적용한다. 미지 버전·손상 데이터와 타 앱 데이터는 보호한다.
- T05에서 자동 검사와 브라우저 검증의 결과, 사람 직접 플레이·청취의 별도 확인 여부를 구별해 남긴다. 이전 원인 미확인 타이틀 복귀 조사는 사용자가 별도로 범위 추가를 선택하지 않는 한 포함하지 않는다.
