# Plan: Pixel Action 첫 스테이지

## Goal
독립 PC 웹 게임의 일반 모드 한 판을 끝까지 플레이한다. 도트 숲에서 이동·가변 점프·마우스 360도 3연타·구르기·공중 내려베기로 일반 적 3종과 2단계 고목 보스를 상대하고, 체크포인트와 로컬 기록을 사용한다. 플레이 시간은 최초 숙련 기준 2~5분을 목표로 실제 플레이 후 조정한다.

## Decisions and boundaries
- [확정 인터뷰](../decisions/2026-11-07-pixel-action-first-stage.md). 기존 Knight Run과 계정·세이브·랭킹을 공유하지 않는다. 기존 폴더와 미푸시 Git 이력을 변경하지 않는다.
- 로컬 브라우저 자동 저장 한 칸. 수동 백업·복구, 하드 모드, 온라인 랭킹, 추가 스테이지와 배포는 제외한다. 로컬 저장은 브라우저 데이터 삭제 시 함께 사라질 수 있다.
- 값과 레벨 좌표는 **검증용 초기값**으로, 사용자 확정 밸런스가 아니다. 테스트와 직접 플레이를 거쳐 조정한다. 실제 이미지의 방향·프레임 수는 사용자 선택인 8방향 캐릭터와 자유 각도 검을 보장하는 범위에서 조정할 수 있다.
- T01에서만 새 독립 Git 저장소를 초기화하고 매 Task 완료 시 지정 커밋을 만든다. 계획 단계에서는 Git 초기화, 소스 작성, 자산 생성, 설치, 배포를 하지 않는다.
