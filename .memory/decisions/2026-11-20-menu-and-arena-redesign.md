# Decisions: Round Selection, Records, and Arena Platform Redesign

- Date: 2026-11-20
- Status: Confirmed

## D01. 이지 라운드 선택 배치 — 사용자 선택

- **Chosen**: 기존 팝업에서 숲·광산을 탭으로 나누고, 선택한 스테이지의 8라운드를 4열 × 2행 타일로 표시한다. 5·7·8라운드 보스 여부와 잠금·도전 가능·클리어 상태를 구분한다. 해금된 타일을 누르면 바로 전투를 시작한다.
- **Rationale**: 한 번에 8개만 보여 주면 팝업이 간결하고, 전투를 시작하기 위한 추가 확인 동작이 필요 없다.

## D02. 기록 화면 구성 — 사용자 선택

- **Chosen**: 타이틀의 기록 팝업에서 이지·하드 모드와 숲·광산 스테이지를 각각 탭으로 선택한다. 이지는 스테이지당 8라운드의 표, 하드는 선택한 스테이지의 최고·최근 기록 카드로 표시한다. 양쪽 모두 최고와 최근의 시간 및 해당 기록의 사망 횟수를 보여 준다. 기록이 없는 항목은 시간 0이나 사망 0으로 표시하지 않는다.
- **Rationale**: 이지는 라운드 단위, 하드는 스테이지 단위로 집계되므로 각각의 비교에 맞는 화면이 필요하다.

## D03. 메뉴 시각 스타일 — 사용자 선택

- **Chosen**: 채팅에서 비교한 시안 중 C(미니멀)를 적용한다. 장식과 테두리는 줄이고 간격, 큰 라운드 번호, 읽기 쉬운 기록 표를 중심으로 구성한다. 숲·광산 색은 작은 포인트로 쓰고 상태는 색과 함께 글자나 기호로 구분한다. 시안의 타일 상세 미리보기는 비교용으로만 쓰며 실제 타일은 D01대로 작동한다.
- **Rationale**: 라운드 번호와 기록 시간을 먼저 읽을 수 있도록 대비와 정보 순서를 정리한다.

## D04. 발판 외형과 배치 개편 — 사용자 선택

- **Chosen**: 발판의 그래픽과 배치를 함께 개편한다. 숲과 광산에 서로 다른 수작업 배치를 여러 개 만들고, 새 시도마다 해당 스테이지 배치 중 하나를 고른다. 배치별로 높이·위치·형태를 다르게 만들어 점프와 전투 경로에 변화를 준다.
- **Rationale**: 점프 거리와 전투 공간을 직접 다듬으면서, 재도전할 때 경로가 달라지는 재미를 유지한다.

## D05. 스테이지별 조형물 — 사용자 선택

- **Chosen**: 자연물·작업 시설·폐허 소재를 조합한다. 숲은 이끼 낀 통나무·굵은 가지·뿌리와 흙·뿌리가 휘감은 석조 유적을, 광산은 채굴 작업대·목재 지지대·폐철로와 철제 구조물·광맥이 드러난 바위 선반을 사용한다. 소재는 스테이지 전체의 조형물 목록에 적용하며, 모든 배치에 모든 소재를 넣을 필요는 없다.
- **Rationale**: 각 조형물이 실루엣만으로도 구분되고 스테이지의 일부처럼 보이게 한다.

## D06. 다층 점프 경로 — 사용자 선택

- **Chosen**: 일부 배치에서는 발판을 위아래로 겹쳐 배치하고 낮은 곳을 밟아 높은 곳으로 갈 수 있게 한다. 모든 발판은 현재 점프 조작으로 도달 가능해야 하며 시작 지점과 바닥 이동·전투 공간을 확보한다. 실제로 밟히는 면과 눈에 보이는 면을 맞춘다.
- **Rationale**: 바닥 전투와 위로 올라가는 경로를 함께 제공하되, 모든 배치를 같은 구조로 만들지 않는다.

## D07. 기존 동작과 저장 호환 — 코드와 기존 결정에서 확인

- **Chosen**: 타이틀과 전투 후 팝업에서 같은 이지 라운드 선택 화면을 사용하고, 기존 뒤로 가기 목적지와 해금 및 집계 규칙을 유지한다. 새 배치는 하드의 새 스테이지 시도와 이지의 새 라운드 세션을 만들 때 고른다. 하드는 진행 중인 스테이지의 라운드 전환과 이어하기에서 배치를 유지한다. 기존 하드 저장에 담긴 발판 배치도 그대로 복원하며 기존 개인 기록·설정·사망 횟수를 보존한다. 발판 개편과 별개인 바닥, 아레나 경계, 점프 조작과 공격 규칙은 유지한다.
- **Rationale**: 이지의 공용 선택기와 저장된 기록을 재사용한다. 하드 이어하기는 이미 발판 위치와 밟히는 높이까지 저장하고 있으므로, 새 배치를 그 자리에 다시 뽑으면 예전 위치에서 이어할 수 없게 된다.

## 구현 계획에 반영할 코드 제약

- `easyRoundSelector.js`의 공용 선택기는 타이틀과 전투 후 팝업에서 모두 호출된다. 기록 화면은 모드마다 이미 집계 단위가 다르며, 화면 개편을 위해 기록 저장 방식을 바꿀 필요는 없다.
- 현재 발판 검증은 가로 구간이 겹치는 발판을 모두 거부한다. 새 다층 배치에서는 실제 높이 간격과 점프 도달 가능성을 검사해야 하며, 예전 저장의 직사각형·불규칙 발판도 계속 읽을 수 있어야 한다.
- 숲 보스의 뿌리 공격은 현재 발판 표면을 참조한다. 다층에서 플레이어가 밟은 층에 예고와 공격이 맞는지 확인한다.
- 예전 무작위 생성 결정은 새 플레이에 한해 D04로 대체한다. 저장돼 있는 배치는 이 변경 때문에 다시 생성하지 않는다.

## 범위 밖에서 발견한 항목

- 로컬 개발 서버 타이틀의 `라운드 선택 (개발용)`은 일반 이지 선택기와 별도 경로다. 개편 대상으로 추가할지는 별도 결정이 필요하다.
