# Decisions: 패링 및 내려찍기 입력 재설계

- Date: 2026-11-24
- Status: Confirmed

## D01. 방어 입력과 방패 종류
- **Chosen**: 우클릭은 패링, `Q`는 원거리 방패로 지정한다. 근접 방패는 추가하지 않는다. `Q` 방패는 기존 우클릭 방패와 같이 누르고 있는 동안 활성화되며, 최대 60틱(1초) 동작한다. 방패 종료 후 180틱(3초) 재사용 대기를 유지한다.
- **Rationale**: 기존 방어 동작의 기능은 유지하면서 키 충돌을 없앤다. 사용자는 방패가 원거리 방어만 한다고 명확히 정정했다.

## D02. 패링 판정과 피해
- **Chosen**: 우클릭 입력 뒤 총 37틱 동안 패링 성공 판정을 허용한다. 처음 23틱은 퍼펙트 패링, 나머지 14틱은 일반 패링으로 판정한다. 퍼펙트 패링은 체력을 잃지 않고, 일반 패링은 기존처럼 체력을 0.5 잃는다. 두 성공 모두 기존 60틱 피격 보호를 적용한다. 패링 재사용 대기 180틱은 입력 시 시작한다.
- **Rationale**: 사용자가 포함 구간 해석을 선택했다. 60틱/초에서 23틱과 37틱은 각각 약 0.383초와 0.617초이며, 요청한 0.382초와 0.618초에 가장 가까운 정수 틱이다.

## D03. 패링 성공 피드백
- **Chosen**: 일반 패링은 현재 작은 청록 충돌 섬광을 유지한다. 퍼펙트 패링은 더 강한 별도 섬광과 구분되는 효과음을 낸다.
- **Rationale**: 이미 구현된 일반 성공 효과를 중복 추가하지 않고, 퍼펙트 성공만 확실히 구별한다.

## D04. 내려찍기 입력과 해금 조건
- **Chosen**: 지상 좌클릭은 일반 공격이다. 공중 진입 후 30틱(0.5초)이 되기 전 좌클릭도 일반 검 공격이다. 30틱이 지난 뒤 내려찍기를 사용할 수 있으면 좌클릭이 내려찍기를 시작한다. 별도 활공 모드나 입력은 만들지 않는다. 내려찍기를 사용할 수 없는 경우(재사용 대기 등)에는 일반 공격으로 처리한다. `E` 키는 내려찍기 입력에서 해제한다.
- **Rationale**: 사용자는 별도 활공 대신 공중 체공시간으로 해금하는 방식을 선택했고, 해금 전 공중 공격은 기존 동작을 유지하기로 했다.

## D05. 내려찍기 후 일반 공격
- **Chosen**: 내려찍기 착지 직후 새 좌클릭으로 다음 틱부터 일반 공격을 시작할 수 있다. 기존 내려찍기 재사용 대기는 다음 내려찍기에만 적용하며 일반 공격을 막지 않는다. 기존 내려찍기 착지 보호와 충격파 동작은 유지한다.
- **Rationale**: 사용자가 내려찍기 뒤 일반 공격을 즉시 사용할 수 있는 흐름을 유지하도록 요청했다. 현재 코드는 착지 다음 틱에 공격을 허용하고 내려찍기 대기는 별도로 관리한다.

## 기존 코드에서 확인한 제약과 관례
- 게임 시뮬레이션은 초당 60틱이다. 요청한 초 단위 값은 정수 틱으로 표현하므로 정확한 실제 길이는 23/60초와 37/60초다.
- 패링은 현재 조준 방향 전방 120도 안의 근접 공격만 막고, 원거리 방패는 원거리 공격만 막는다. 이 범위 규칙은 변경하지 않는다.
- 성공한 방어는 현재 피해 경직 없이 60틱 피격 보호를 준다. 이 동작을 퍼펙트와 일반 패링 모두에 유지한다.
- 플레이어 저장 상태는 필드와 타이머 범위를 엄격하게 검증한다. 새 공중 체공 타이머를 저장 상태에 추가한다면 기본값, 검증, 기존 저장 데이터 복구도 함께 갱신해야 한다. 패링 최대 타이머 검증도 37틱으로 늘려야 한다.
- 설정 화면과 README에는 현재 키와 0.25초 패링 안내가 있으므로, 구현 시 새 키와 판정 시간을 함께 갱신한다.

## 범위 밖에서 발견한 사항
- 일반 패링 성공 시 이미 12틱 동안 작은 청록 충돌 섬광이 보이고, 패링 동작 초반에는 칼날 반짝임이 있다. 일반 성공에는 기존 충돌 섬광을 사용하고 별도 중복 섬광을 추가하지 않기로 했다.
- 현재 내려찍기는 36틱 재사용 대기와 15틱 착지 보호를 사용한다. 사용자가 변경을 요청하지 않아 유지한다.
