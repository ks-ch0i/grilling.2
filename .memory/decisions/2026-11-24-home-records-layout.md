# Decisions: Home Records Layout

- Date: 2026-11-24
- Status: Confirmed

## D01. 홈 기록 화면 배치 — 사용자 선택
- **Chosen**: 홈의 `기록`을 열면 왼쪽에 회사 순위, 오른쪽에 내 기록을 한 화면에 표시한다. 이지·하드와 숲·광산은 상단에서 공통으로 고른다. 홈의 `뒤로`는 메인 메뉴로 돌아간다.
- **Rationale**: 화면을 오가지 않고 현재 도전의 회사 순위와 내 기록을 볼 수 있다.

## D02. 이지 라운드 선택 — 사용자 선택
- **Chosen**: 내 기록에는 선택한 스테이지의 01~08라운드를 모두 보여주고 각 행에 최고·최근 기록을 표시한다. 라운드 번호로 회사 순위를 선택할 수 있고, 선택된 행을 강조한다. 내 기록이 없는 라운드도 선택할 수 있다. 번호 선택 시 회사 순위의 라운드 제목과 목록을 갱신하고 내 기록표는 유지한다.
- **Rationale**: 개인 기록 전체를 훑으면서 원하는 라운드의 회사 순위를 바로 볼 수 있다.

## D03. 좁은 화면 — 사용자 선택
- **Chosen**: 두 영역을 나란히 배치하기 어려울 때는 내 기록을 위에, 회사 순위를 아래에 놓는다. 같은 모드·스테이지·라운드 선택이 두 영역에 적용된다.
- **Rationale**: 내 기록표에서 라운드를 고르고 아래로 내려가 순위를 확인할 수 있다.

## D04. 기본 선택 — 사용자 선택
- **Chosen**: 홈에서 `기록`을 열 때마다 이지 · 숲 · 01라운드로 시작한다.
- **Rationale**: 기존의 이지·숲 기본값을 이어가고, 기록 화면을 열면 첫 라운드의 순위를 바로 볼 수 있다.

## D05. 내 회사 순위 — 사용자 선택
- **Chosen**: 회사 상위 10명과 내 순위는 왼쪽에 둔다. 기존과 같이 내 순위가 10위 밖이면 표 하단에 `내 기록` 행을 표시한다. 오른쪽은 내 최고·최근 기록을 보여준다.
- **Rationale**: 회사 기준 순위는 한곳에서 읽고 개인 플레이 기록은 별도로 훑을 수 있다.

## D06. 시각 표현과 선택 조작 — 사용자 요청과 기존 메뉴 기준
- **Chosen**: 기존 게임 UI의 어두운 바탕과 숲·광산 색을 사용한다. 테두리와 장식은 줄이고, 영역 제목과 열 간격으로 순위·이름·시간·사망 횟수를 구분한다. 라운드 선택은 키보드로도 조작할 수 있으며, 현재 선택을 색과 선택 표시로 함께 드러낸다.
- **Rationale**: 게임 분위기를 이어가면서 긴 이름이나 숫자가 많은 화면에서도 기록을 읽기 쉽다.

## D07. 기록 단위와 조회 상태 — 기존 코드에서 확인
- **Chosen**: 이지는 스테이지와 라운드, 하드는 스테이지 단위로 기존 순위와 저장 데이터를 사용한다. 하드의 내 기록은 해당 스테이지의 최고·최근 카드로 표시한다. 회사 순위는 기존 시간·사망 수 정렬과 사내 접근 권한을 유지하고, 현재 선택에 해당하는 순위만 조회한다. 조회 중·빈 순위·오래된 순위·재시도는 회사 순위 영역에 표시한다. 회사 순위가 지연되거나 조회할 수 없는 경우에도 내 기록을 보여준다. 개인 기록이 없으면 `기록 없음` 또는 대시로 표시한다.
- **Rationale**: 회사 순위와 개인 저장 기록의 집계 방식을 재사용하고, 네트워크 상태와 무관하게 내 기록을 확인할 수 있다.

## 범위 밖에서 확인한 항목

- 하드 클리어 결과의 `회사 순위`도 같은 기록 화면 코드를 호출한다. 홈 개편 시 결과 화면에서 선택한 하드 스테이지 순위로 바로 들어가고 결과로 돌아오는 기존 경로를 보존해야 한다.
- 회사 순위 서버는 최대 10개 행을 내려주고, UI는 내 순위가 11위 이상일 때 내 행을 별도로 붙인다. 공동 순위로 10개 행의 표시 범위와 순위 숫자가 달라질 때의 별도 정책은 이번 결정에 포함하지 않았다.
