# 결정: 라운드 기반 게임 진행 방식

- 날짜: 2026-11-16
- 상태: 확정

## D01. 스테이지 구조와 진행
- **선택**: 횡스크롤 진행을 스테이지별 한 화면 고정 아레나로 바꾼다. 스테이지마다 8라운드를 진행한다. 8라운드 클리어 화면에서 다음 스테이지를 선택하면 기존 순서대로 숲에서 광산으로 이동한다. 광산은 마지막 스테이지다.
- **이유**: 사용자가 스테이지당 8라운드와 라운드 클리어 후 다음 스테이지 이동을 정했다. 기존 스테이지 순서는 숲 다음 광산이다.

## D02. 일반 라운드 몬스터 수
- **선택**: 1~4라운드는 각각 1, 2, 3, 4마리다. 5라운드는 보스만 등장한다. 6라운드는 몬스터 6마리다. 7·8라운드는 보스와 스테이지별 몬스터 종류를 한 마리씩 등장시킨다.
- **이유**: 사용자가 각 라운드의 수와 5라운드 보스전 구성을 정했다.

## D03. 몬스터 종류 선택
- **선택**: 1~4·6라운드는 해당 스테이지의 세 종류 중에서 몬스터 종류를 무작위로 정한다. 정해진 총 마릿수는 유지한다. 7·8라운드는 세 종류를 한 마리씩 고정 배치한다.
- **이유**: 사용자가 일반 라운드는 종류를 무작위로 섞고, 7·8라운드는 해당 스테이지의 모든 종류를 한 마리씩 내도록 정했다.

## D04. 보스 라운드와 페이즈
- **선택**: 별도의 10라운드 규칙은 두지 않는다. 숲 Guardian은 5·7라운드에서 1페이즈 공격만 사용하고, 처치할 때까지 전투한다. 8라운드는 1·2페이즈를 모두 진행한다. 광산 Machine은 5·7라운드에 등장한다. 광산 8라운드는 기존 순서대로 Machine, Worm 1페이즈, Worm 2페이즈를 진행한다.
- **이유**: 사용자가 10라운드 규칙을 제외하고, 숲 보스의 1페이즈 공격 유지와 광산 Worm의 기존 페이즈 순서를 확정했다.

## D05. 체력 회복과 라운드 전환
- **선택**: 매 라운드 시작 때 플레이어 체력을 전부 회복한다. 해당 라운드의 보스와 몬스터를 모두 처치하면 클리어 표시 후 2초 뒤 다음 라운드를 자동 시작한다.
- **이유**: 사용자가 라운드별 체력 회복과 2초 뒤 자동 진행을 선택했다.

## D06. 사망과 스테이지 재시도
- **선택**: 사망하면 해당 스테이지 1라운드부터 다시 시작하고 데스카운트를 1 증가시킨다. 경과 시간은 초기화하지 않고 스테이지 첫 라운드부터의 총 시간을 기록한다. 데스카운트는 8라운드 클리어까지 누적한다. 클리어한 스테이지를 다시 시도하면 새 데스카운트로 시작한다.
- **이유**: 사용자가 사망 후 1라운드 재시작, 총 시간 유지, 스테이지별 데스카운트 누적을 확정했다.

## D07. 최고기록
- **선택**: 스테이지별로 최단 클리어 시간을 최고기록으로 저장한다. 기록 화면에는 데스카운트도 함께 표시한다.
- **이유**: 사용자가 기존 최단 시간 기준을 유지하고 데스카운트를 표시하도록 정했다.

## D08. 스테이지 클리어 화면
- **선택**: 보기 좋은 클리어 화면에 기록과 홈·다음 스테이지·다시 시도 버튼을 둔다. 홈은 타이틀로, 다음 스테이지는 다음 스테이지의 1라운드로 이동한다. 다시 시도는 클리어한 스테이지의 1라운드를 새 데스카운트로 시작한다. 마지막 광산 화면에는 홈과 다시 시도만 둔다.
- **이유**: 사용자가 요청한 버튼 구성과 마지막 스테이지의 다음 버튼 제외를 반영했다.

## D09. 기존 저장 데이터
- **선택**: 새 라운드 버전을 시작할 때 이전 저장 데이터를 전부 초기화한다. 기록, 해금 상태, 설정, 진행 상황을 새 게임 상태로 시작한다.
- **이유**: 사용자가 기존 저장 데이터를 모두 초기화하기로 정했다.

## D10. 이어하기와 새 저장 데이터
- **선택**: 새 버전에서도 현재의 이어하기와 새로고침 후 복구 동작을 유지한다. 새 저장 상태에는 현재 라운드와 무작위 선택 상태를 저장한다.
- **이유**: 기존 코드는 진행 상태를 주기적으로 저장하고 새로고침 후 복구한다. 사용자는 이 기능을 제거하라고 요청하지 않았다.
