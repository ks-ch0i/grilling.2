# 개발용 라운드 선택

개발 서버(`npm run dev`)의 제목 화면에서 **라운드 선택 (개발용)**을 누르면 다음 지점에서 바로 연습할 수 있다.

- 숲 시작과 숲 보스
- 광산 시작, 기계 보스, 거대 벌레

연습은 체력 최대치로 시작한다. 사망하면 선택한 연습 지점에서 다시 시작한다. 연습의 진행·클리어 기록은 기존 저장이나 해금 상태에 반영하지 않는다. 기계 보스를 선택해 쓰러뜨리면 기존 설계대로 거대 벌레가 이어서 등장한다.

개발 서버를 시작하기 전에 `VITE_DEV_ROUND_SELECTOR=false`를 설정하면 메뉴를 끌 수 있다. PowerShell 예:

```powershell
$env:VITE_DEV_ROUND_SELECTOR = 'false'
npm.cmd run dev
```

환경 변수를 바꾼 뒤에는 개발 서버를 다시 시작한다. 배포 빌드에서는 이 환경 변수와 관계없이 선택 메뉴와 연습 진입이 비활성화된다.

## 배포 후 관리자 권한 연결

현재 게임에는 사용자 인증, 관리자 계정, 권한을 검증하는 서버가 없다. 따라서 브라우저 변수나 메뉴 감추기를 관리자 권한으로 취급하지 않는다. 배포 후에는 서버에서 인증된 사용자와 관리자 권한, 기능 활성화 여부를 검증하는 방식으로 별도 연결해야 한다. 서버 검증이 준비되기 전까지 배포 빌드에서는 이 기능을 열지 않는다.
